# 时效性判定与排序规则（单一真源）

> 本文件是**档位换算、时效判定、事件分级、排序、结论**的唯一权威定义。
> `scripts/timeliness-rank.mjs` 中的常量与判定分支必须与本文件逐行一致；若二者出现分歧，
> 以本文件为准并同步修脚本。`SKILL.md` 与其它 references 只引用，不复写规则。

**两条硬性原则**：

1. **换算、档位、计数、排序、结论全部由脚本计算**，LLM 只负责取数、语义归并与"主叙事时效"的推理判断。
2. **拿不准就降级、就标注，绝不编造**；数据缺失或置信度低一律**不淘汰**，只在档位/排序上保守处理并留痕。

## 1. 市场规模档位（由脚本从原值换算）

### 1.1 单位与换算

统一折算为**人民币亿元**（保留 2 位小数）：

| 单位 | 币种 | 折人民币亿元 |
|------|------|-------------|
| `亿元` | CNY | ×1 |
| `万元` | CNY | ÷10000 |
| `万亿元` | CNY | ×10000 |
| `亿美元` | USD | ×`config.fx.usdcny` |

- `亿元`/`万元`/`万亿元` 只能配 `CNY`，`亿美元` 只能配 `USD`；不自洽 → `E_INVALID_UNIT`。
- 出现 `USD` 而 `config.fx.usdcny` 缺失 → `E_USD_WITHOUT_FX`。
- 单位未出现在 `config.units.市场规模` 声明集合内 → `E_INVALID_UNIT`。
- 不接受自造单位（如 `万美元`、`千亿元`）→ `E_INVALID_UNIT`。

### 1.2 定档（边界一律取「大于等于」，即 `>=`）

| 换算值（人民币亿元） | 档位 |
|--------------------|------|
| `>= 10000` | `万亿级` |
| `>= 1000` 且 `< 10000` | `千亿级` |
| `>= 100` 且 `< 1000` | `百亿级` |
| `< 100` | `百亿级以下`（记 `W_MARKET_BELOW_100YI`） |
| 未取到（`null` 或 `[数据暂不可用]`） | `未标注`（记 `W_MARKET_UNRESOLVED`） |

### 1.3 近似口径（`precision == "近似"`）

近似口径必须齐备 `caliber` / `caliber_vs_target ∈ {偏大, 偏小}` / `caliber_note` / `tag == "[待验证]"`
四件套，缺任一 → `E_APPROX_CALIBER_INCOMPLETE`。

定档修正（**确定性、可复算**）：

| `caliber_vs_target` | 档位处置 |
|---------------------|---------|
| `偏大` | **向下取一档**：`万亿级→千亿级`、`千亿级→百亿级`、`百亿级→百亿级以下`、`百亿级以下→百亿级以下`；记 `W_PROXY_DOWNGRADED` |
| `偏小` | 保持原档位（偏小不损害"够不够大"的结论），仍强制 `[待验证]` |

> 定档永远基于**修正后**的档位；`换算(亿元人民币)` 保留原始换算值，便于复核。

### 1.4 数据来源形态（脚本 `extract` 自动嗅探）

优先级从高到低：`预测.amount` / `要素明细.预测.amount`（结构化） > `预测3-5年市场规模` 字符串解析 > markdown 表格单元格。

字符串解析规则：取文本中**第一个**「数字 + 单位」组合（`万亿元`/`亿元`/`万元`/`亿美元`），支持千分位与小数；
例 `12,025.68亿元人民币（原值 1,689亿美元，2026 测算，3年）` → `12025.68 亿元` → `万亿级`。

## 2. 主叙事时效（Step 1，LLM 判断 + 脚本执行淘汰）

### 2.1 判定

LLM 逐方向给出 `所在产业链` / `主叙事逻辑`（≤40 字）/ `落地判据` / `落地时间档位 ∈ {短期, 中期, 长期, 未标注}`
与 `source{type,detail,year}` / `confidence ∈ {高,中,低}`。

| 档位 | 口径 | 处置 |
|------|------|------|
| `短期` | 主叙事落地事件在 **1-2 年**内发生（国产替代率 >50%、政策规划目标达成、规模量产爬坡等） | 保留 |
| `中期` | **3-5 年** | 保留，标「备选」**标签**（不参与排序） |
| `长期` | **5 年以上**（实验室走向商业化、尚需多轮技术迭代） | **淘汰**，原因码 `E1_NARRATIVE_LONG_TERM` |
| `未标注` | 证据不足，无法判定 | **保留**，记 `W_NARRATIVE_UNRESOLVED`，备注 `[待验证]` |

**不误杀原则**：`落地时间档位 ∈ {未标注}` 或 `confidence == 低` → 一律保留、不淘汰，只做留痕与 `[待验证]` 标注。

### 2.2 淘汰原因码

| 原因码 | 条件 | 说明 |
|--------|------|------|
| `E1_NARRATIVE_LONG_TERM` | `主叙事.落地时间档位 == 长期` 且 `confidence ∈ {高, 中}` | 唯一淘汰通道；`confidence == 低` 时改判 `未标注` 保留 |

统计写入 `剔除原因统计`，清单写入 `淘汰清单[]`，原文留在附录 A。

## 3. 事件驱动优先级（Step 3，聚合 + 兼容分级）

### 3.1 输入形态

| 形态 | 判定 | 处置 |
|------|------|------|
| `sortlogic` | 顶层 `细分产业方向[]` 的元素含 `排序逻辑`（`daily-event-direction-screen` 结果） | 直接按标准名**求和**七档计数（上游已去重，不再二次去重） |
| `impact` | 顶层含 `影响环节[]`（`event-chain-navigator` 原始输出） | 按 §3.2–§3.4 **现场分级**后计数 |
| 其它 | 二者皆无 | 跳过该文件，记 `W_SKIPPED_FILE`（不静默） |

全部文件都不含可用结构 → `E_NO_SORTLOGIC_FIELD` 阻断。

### 3.2 枚举规范化（仅 `impact` 形态）

| 字段 | 规范化 | 规范值 |
|------|--------|--------|
| `影响方向` | 去空格/全角空格，含关键词即判 | `利好` \| `利空` \| `中性` |
| `影响定级` | 去空格、`级` 可省、大小写不敏感 | `S` \| `A` \| `B` \| `C` |
| `传导强度` | 删除 `传导` 二字；`/`、`／`、`|` 等价；空格删除 | 6 值之一（见下） |
| `推理置信度` | 去空格 | `高` \| `中` \| `低` |

`传导强度` 六值及其二元组：

| 规范值 | level | strength |
|--------|-------|----------|
| `一级/高` | 1 | 3 |
| `一级/中` | 1 | 2 |
| `一级/低` | 1 | 1 |
| `二级/高` | 2 | 3 |
| `二级/中` | 2 | 2 |
| `二级/低` | 2 | 1 |

### 3.3 逐层排除（`impact` 形态，命中即停，一条只记一个原因码）

| 顺序 | 原因码 | 条件 |
|------|--------|------|
| 1 | `R1_LOW_CONFIDENCE` | `推理置信度 = 低` |
| 2 | `R2_BEARISH_S_HIGH` | `影响方向 = 利空` 且 `影响定级 = S` 且 `推理置信度 = 高` |
| 3 | `R3_BEARISH_A_L1_HIGH` | `影响方向 = 利空` 且 `影响定级 = A` 且 `传导强度 = 一级/高` 且 `推理置信度 = 高` |
| 4 | `D1_NOT_BULLISH` | `影响方向 ≠ 利好`（含 `中性`、残留 `利空`、方向缺失） |
| 5 | `D2_CONFIDENCE_NOT_HIGH` | `推理置信度 ≠ 高`（含 `中`、置信度缺失） |

> 与上游 `daily-event-direction-screen/references/ranking-rules.md` §1–§2 完全一致：只有「利好 + 推理置信度 高」进入分级。

### 3.4 优先级阶梯（`impact` 形态，仅"利好 + 高置信"，自上而下命中即停）

| # | 影响定级 | 传导强度 | 优先级 |
|---|---------|---------|--------|
| 1 | S | 一级/高 | `最高` |
| 2 | S | 一级/中 | `非常高` |
| 3 | S | 二级/高 | `非常高` |
| 4 | S | 二级/中 | `高` |
| 5 | A | 一级/高 | `高` |
| 6 | A | 一级/中 | `中高` |
| 7 | A | 二级/高 | `中高` |
| 8 | A | 二级/中 | `中` |
| 9 | B | 一级/高 | `中` |
| 10 | B | 一级/中 | `中低` |
| 11 | B | 二级/高 | `中低` |
| — | 其余利好+高置信组合（`B/二级/中`、`C` 任意、含 `低` 的传导强度、不可解析） | — | `低` + `W_UNCLASSIFIED_ROW` |

- `B/二级/中` **不在**枚举内，按"其余"落 `低`。
- 缺 `影响定级` 或 `传导强度`，但 `影响方向=利好`、`推理置信度=高` → 落 `低`，记 `W_MISSING_FIELD` + `W_UNCLASSIFIED_ROW`。
- 缺 `细分产业方向` 或为空串 → 整条丢弃，记 `W_MISSING_FIELD`（原因码 `E_SKIPPED_ENTRY`）。

### 3.5 去重（仅 `impact` 形态）

指纹 `标准名 + 影响方向 + 影响定级 + 传导强度 + 推理置信度` 去重，保留首条，记 `W_DUPLICATE_DROPPED`
（防止同一条目重复放大档位计数）。`sortlogic` 形态不二次去重——不同事件文件里的相同方向是**不同证据**，应累加。

### 3.6 名称归并

- 以用户给出的 `[{细分产业方向}]` 标准名为准。
- 文件内名称先按归一化（去空格/全角/括号差异）精确命中标准名或 `原名[]`；未命中再查
  `--canonical <json>` 映射，再查**只读**的 `shared/industry_segment_direction_dictionary.json`（本技能不回写词典）。
- 仍无法映射的方向 → 记 `W_UNMATCHED_SOURCE_DIRECTION` 并**忽略该条**（不并入、不静默）。
- 用户方向在任何来源文件中都没有记录 → 七档全 `0` + `W_NO_EVENT_EVIDENCE`（不淘汰）。

### 3.7 事件文件集合缺失时的现取（LLM + 工具）

用户同意后：`wind-mcp-skill financial_docs.get_financial_news` → `web_search`，窗口默认**近 90 天**
（起止写入 `meta.窗口.事件`），按 §3.2–§3.4 **现场分级**后写入 `事件驱动.排序逻辑`，来源逐条落《证据附录》。
用户拒绝 → 全 `0` + `W_NO_EVENT_EVIDENCE`，继续出表。

## 4. 排序（脚本执行，LLM 不参与）

三键依次比较（**降序**，即优劣顺序在前）：

```
排序键 1：预测3-5年市场规模档位   万亿级 > 千亿级 > 百亿级 > 百亿级以下 > 未标注
排序键 2：产业链层级            上游原材料/耗材 > 上游核心零部件/设备 > 中游制造/集成 > 下游应用 > 未标注
排序键 3：事件驱动受益程度        七元组 (最高, 非常高, 高, 中高, 中, 中低, 低) 逐位降序比较
兜底：   标准名字典序升序        （码位序，保证同输入同输出）
```

- **主叙事时效档位不是排序键**（短期/中期同场竞争，只作标签与备注）。
- 任一键相等则进入下一键；三键全等再按标准名升序。
- 未取到数的条目（`未标注`）排在同键中最末，不被删除。

## 5. 结论与 Top N 并排扩展

```
N = --top（默认 config.top_n，再默认 5）
k = min(N, 行数)
while k < 行数 且 key(行[k]) == key(行[N-1]) :  k += 1
前 k 行 = 通过；其余 = 未通过
```

- `key(行)` = 三键组成的确定性字符串。
- `k > N` 时记 `W_TIE_EXTENDED_TOP`（并排导致通过数 > N）。
- 行数 ≤ N 时全部 `通过`。
- 主叙事时效为**长期**的方向不进主表、不参与结论，只进 `淘汰清单[]`。

脚本一律重算以下字段；输入值与重算值不一致时记 `W_FIELD_RECOMPUTED` 并**以脚本值为准**（不因算术笔误阻断整轮）：

| 字段 | 重算公式 |
|------|---------|
| `预测3-5年市场规模.换算(亿元人民币)` | 原值 × 单位系数 ×（USD 时 ×`fx.usdcny`），保留 2 位小数 |
| `预测3-5年市场规模.档位` | §1.2 定档 + §1.3 近似修正 |
| `事件驱动.来源条目数` | 七档计数之和 |
| `排名` / `结论` / `剔除原因统计` | §4–§5 |
