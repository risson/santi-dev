## 2. 主表（markdown，按三键排序）

表头**固定 7 列且顺序固定**，不得增删列或改名：

```markdown
| 细分产业方向 | 主叙事逻辑 | 落地时间 | 预测3-5年市场规模 | 产业链层级 | 事件驱动受益程度 | 结论 |

```

**单元格格式**

| 列 | 格式 | 示例 |
|----|------|------|
| 细分产业方向 | 标准名 | `固态电解质材料` |
| 主叙事逻辑 | ≤40 字一句话 | `以固态电池产业升级为核心，最终普及到整个新能源汽车产业链` |
| 落地时间 | `短期（1-2年）` / `中期（3-5年）` / `长期（5年以上）` / `未标注（存疑）` | `中期（3-5年）` |
| 预测3-5年市场规模 | `{档位}（{千分位}亿元人民币）`；未取数写 `未标注（未取数）`；近似口径追加 `；近似口径[待验证]` | `万亿级（12,025.68亿元人民币）` |
| 产业链层级 | 四层枚举之一；缺失写 `未标注` | `上游原材料/耗材` |
| 事件驱动受益程度 | `最高{a} / 非常高{b} / 高{c} / 中高{d} / 中{e} / 中低{f} / 低{g}`；七档全 0 时追加 `（无事件证据）` | `最高0 / 非常高0 / 高2 / 中高1 / 中0 / 中低0 / 低0` |
| 结论 | `通过` / `未通过` | `通过` |

**排序**：见 `references/ranking-rules.md` §4；**结论**：见 §5（前 N 名通过，三键并排一并通过）。

## 4. 对话回复规范

用户未指定输出方式时默认落盘；落盘后**只报**：

1. 结果文件路径（JSON + markdown）
2. 一行摘要：`共 N 个方向：保留 a（通过 c）、长期淘汰 b`
3. **淘汰原因统计**（各原因码计数）+ 淘汰清单方向名
4. **`[待验证]` 清单**：第三方测算/互联网来源的要素，逐条列出方向与要素名
5. 排序与结论口径一行：`排序 = 市场规模档位 → 产业链层级 → 事件驱动七档；时效档位仅作标签`
6. 免责声明：`数据来源：Wind 金融终端、公开信息 | AI 生成，仅供参考，不构成投资建议`

不重复整段 JSON；用户明确要求时才打印全文或改用 `--stdout`。

## 5. 文件落位

| 项 | 规则 |
|----|------|
| 默认目录 | 用户指定 `--out`；未指定 → `<当前工作区根目录>/timeliness-rank/` |
| 结果文件 | `timeliness-rank_<YYYY-MM-DD>.json` 与 `timeliness-rank_<YYYY-MM-DD>.md` |
| Step 2 产物 | `<输出目录>/market-tier_<YYYY-MM-DD>.json` 与 `.md` |
| Step 3 产物 | `<输出目录>/event-aggregate_<YYYY-MM-DD>.json` 与 `.md` |
| 中间数据 | `<输出目录>/inventory.json`（Step 4 生成，供复核与重跑） |
| 编码 | UTF-8 无 BOM，LF 换行，末尾换行；纯 JSON 不包代码块、无前后缀文字 |
| 同名文件 | 默认覆盖，并在回复中说明覆盖的是哪个路径 |
| `--stdout` | 只打印 JSON 到标准输出，不落盘；摘要与警告改走 **stderr**，保证 stdout 是纯 JSON |
| 禁止 | 不得写死绝对路径/用户名/平台专有路径；不得写技能自身目录；运行期不得写入 `shared/`（共享词典只读） |
| 写入失败 | 如实说明原因（含沙箱/权限拒绝），改为对话输出，**不得谎报已写入** |
