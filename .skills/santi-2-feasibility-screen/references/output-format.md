## 2. 主表（markdown）

表头**固定 10 列且顺序固定**（你的 9 列 + 末列「结论」），不得增删列或改名：

```markdown
| 细分产业方向 | 政策条目数及级别 | 产业目录内的类别 | 产业投资事件数量 | 总投资金额 | 订单增长率 | 预收款增长率 | 扩产公告数量 | 企业落地证据置信度 | 结论 |
|------|------|---------|---------|---------|---------|---------|------|------|------|
```

**单元格格式**（为不增列又满足「所有口径必须给出来源和置信度」，**置信度内联在对应单元格**，来源进 §3 证据附录）：

| 列 | 格式 | 示例 |
|----|------|------|
| 细分产业方向 | 标准名 | `固态电解质材料` |
| 政策条目数及级别 | `{n}（国家级{a}/部委级{b}；置信度：{X}）`；`n == 0` 写 `0（置信度：{X}）` | `5（国家级2/部委级3；置信度：高）` |
| 产业目录内的类别 | `{类别}（《{目录名称}》；置信度：{X}）`；允许类追加 `-目录未列名` | `允许类-目录未列名（《产业结构调整指导目录（2024年本）》；置信度：中）` |
| 产业投资事件数量 | `{n}（置信度：{X}；金额覆盖率 {p}%）` | `4（置信度：中；金额覆盖率 75%）` |
| 总投资金额 | `{千分位}{单位}`，非人民币写 `≈{换算值}亿元人民币`；末尾 `（置信度：{X}）` | `12.6亿元（置信度：中）` |
| 订单增长率 | `{1 位小数}%（置信度：{X}）`；近似口径未命中写 `未命中（近似口径已向下修正）`；未取数写 `未取数` | `23.5%（置信度：高）` |

## 4. 对话回复规范

用户未指定输出方式时默认落盘；落盘后**只报**：

1. 结果文件路径（JSON + markdown）
2. 一行摘要：`共 N 个方向：通过 a / 存疑 b / 淘汰 c`
3. **淘汰原因统计**（各原因码计数）+ 存疑清单（方向 + 受影响维度）
4. **`[待验证]` 清单**：第三方测算/互联网来源的要素，逐条列出方向与要素名
5. 目录版本一行：`目录：产业结构调整指导目录（2024年本）（本地 sha256 前 12 位 …，检索状态：本地现行）`
6. 免责声明

不重复整段 JSON；用户明确要求时才打印全文或改用 `--stdout`。

## 5. 文件落位

| 项 | 规则 |
|----|------|
| 默认目录 | 用户指定 `--out`；未指定 → `<当前工作区根目录>/feasibility-screen/` |
| 文件名 | `feasibility-screen_<YYYY-MM-DD>.json` 与 `feasibility-screen_<YYYY-MM-DD>.md` |
| 中间产物 | `<输出目录>/inventory.json`（Step 5 生成，供复核与重跑） |
| 编码 | UTF-8 无 BOM，LF 换行，末尾换行；纯 JSON 不包代码块、无前后缀文字 |
| 同名文件 | 默认覆盖，并在回复中说明覆盖的是哪个路径 |
| `--stdout` | 只打印 JSON 到标准输出，不落盘；摘要与警告改走 **stderr**，保证 stdout 是纯 JSON |
| 禁止 | 不得写死绝对路径/用户名/平台专有路径；不得写技能自身目录；运行期不得写入 `shared/` |
| 写入失败 | 如实说明原因（含沙箱/权限拒绝），改为对话输出，**不得谎报已写入** |
