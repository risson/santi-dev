# 三关淘汰与存疑规则（单一真源）

本文件定义 `SKILL.md` Step 2–4 的全部判定：政策支持度（Gate P）、产业资本投入（Gate C）、企业落地证据（Gate L），以及结论聚合与排序。脚本 `scripts/feasibility-screen.mjs` 按本文件实现，`SKILL.md` 与 `references/data-collection.md` 只引用不重复。

**核心原则**：`淘汰` 需要**证据充分**（该关判定置信度达标且关键字段齐备）；**数据缺失或置信度为低一律不淘汰，进入「存疑」并排尾**，同时注明受影响的维度。

---

## 0. 结论三态与维度置信度

| 结论 | 含义 | 排序位置 |
|------|------|---------|
| `通过` | 三关全部通过 | 最前 |
| `存疑` | 无任何关淘汰，但至少一关因数据缺失/低置信度无法判定 | 中间 |
| `淘汰` | 至少一关命中淘汰条件且证据充分 | 最后 |

- **维度置信度 = min(该维度所有必需数据点的置信度)**（取最保守）。
- 依赖本地目录文档的 P2 判定，其置信度规则见 `references/data-collection.md` §3.3。
- 结论聚合：任一关 `淘汰` → 方向 `淘汰`（列出全部命中原因码，不早停）；否则任一关 `存疑` → `存疑`；否则 `通过`。

## 1. Gate P：政策支持度

### 1.1 数据点

| 字段 | 含义 | 必需 |
|------|------|------|
| `政策.条目数` | 近 2 年（24 个月滚动）**重大政策**条目数 | 是 |
| `政策.级别分布` | `{国家级, 部委级, 省级及以下}` | 是 |
| `政策.明细[]` | 每条：标题/发布机构/文件号/发布日期/级别/来源/置信度 | 是（条目数 > 0 时） |
| `政策.目录.类别` | `鼓励类` \| `允许类` \| `限制类` \| `淘汰类` | 是 |
| `政策.目录.命中[]` | `catalog` 子命令的命中明细（类别/章/子章/条目/命中词） | 是 |
| `政策.目录.检索词[]` | ≥2 个检索词 | 是 |
| `政策.目录.版本` / `.sha256` | 本地目录文档版本与文件摘要 | 是 |

- **「重大政策」定义**：中共中央／国务院／国家部委（发改委、工信部、科技部、财政部、能源局等）发布的**规划、纲要、目录、行动方案、实施方案、专项管理办法、试点通知、补贴政策**。地方文件**不计入**条目数（可作辅助证据写入备注）。
- **「允许类」口径**：《产业结构调整指导目录》只列鼓励/限制/淘汰三类，未列名即允许类。用户口径中的「不在国家产业政策目录内」与「允许类」**合并为同一类**，备注写「目录未列名」。
- 若 `catalog` 命中多个类别 → **按限制/淘汰优先**取（对政策支持度更不利），备注写明冲突。

### 1.2 判定（按顺序命中即定档）

| 序号 | 条件 | 处置 | 原因码 | 备注写入 |
|------|------|------|--------|---------|
| P0 | `类别 == 鼓励类` 且 `条目数 >= 1` | **通过** | — | 无 |
| P1 | `（条目数 == 0 或 类别 ∈ {允许类, 限制类, 淘汰类}）` 且 `维度置信度 == 高` | **淘汰** | `E1_POLICY_NOT_SUPPORTED` | 子码 + 命中明细 |
| P2 | 同 P1 条件，但 `维度置信度 ∈ {中, 低}` | **存疑** | `W_POLICY_UNRESOLVED` | `政策数据不足（置信度 {X}），未适用淘汰` |

**子码**（可多个并存，取首个用于主表显示）：

| 子码 | 触发 |
|------|------|
| `E1A_ZERO_POLICY` | `条目数 == 0`（近 2 年无重大政策，且已双源穷尽） |
| `E1B_NOT_ENCOURAGED` | `类别 == 允许类`（含"目录未列名"） |
| `E1C_RESTRICTED_OR_ELIMINATED` | `类别 == 限制类` 或 `淘汰类` |

### 1.3 边界（脚本断言）

- 限制类/淘汰类**无论政策条目多少**都淘汰（条目数 ≥ 1 不构成豁免）。
- `鼓励类` + `条目数 == 0` → 按"OR"语义**淘汰**（子码 `E1A_ZERO_POLICY`）。
- 条目数恰为 `0` 与恰为 `1` 是两种不同结果；`条目数 == 0` 的置信度上限为「中」**除非** Wind 新闻检索与 web_search 双源穷尽且检索留痕（此时可判高）。
- 维度置信度不是「高」时**永不淘汰**（只能存疑），即使 P1 条件成立。

## 2. Gate C：产业资本投入（数据源仅 `web_search`）

### 2.1 数据点

| 字段 | 含义 | 必需 |
|------|------|------|
| `产业资本.事件[]` | 每条：投资主体/被投对象/投资形式/投资金额/资金用途/事件日期/来源/归属判定/归属理由/置信度 | 是 |
| `产业资本.已排除事件[]` | 判为 `不属于` 的事件及理由 | 条件（有排除时） |
| `产业资本.归属事件数` | 去重后、判为属于且**金额可得**的事件数 | 是（由脚本复算校验） |
| `产业资本.合计金额` | 归属事件金额合计（统一人民币亿元） | 是（脚本复算） |
| `产业资本.覆盖率` | 金额可得事件数 ÷ 判为属于的事件数 | 由脚本计算 |
| `产业资本.置信度` | 见 §2.3 | 是 |

### 2.2 计数与金额口径（脚本强制）

- **主体范围**：国家部委（科技部/工信部/发改委等）、国家级引导基金、省级引导基金、市县级产业基金及其受托管理机构。**排除**纯市场化 VC/PE。
- **窗口**：近 12 个月（起止写入 `meta.窗口.资本`）。
- **去重**：`(投资主体, 被投对象, 事件日期)` 相同只计 1 起；同一被投对象的不同轮次/不同主体各计 1 起（备注注明）。
- **金额缺失的事件**：**不计入事件数、不计入金额**，记 `W_EVENT_AMOUNT_MISSING`，并进入覆盖率分母。
- **合计金额**：只累加口径匹配的事件，统一折算人民币亿元（换算留痕；美元无汇率时该事件不计入，记 `W_FX_ASSUMED`）。
- **覆盖率** = 金额可得事件数 ÷ 判为属于的事件数；**归属事件数恒为 0 且检索已执行**时覆盖率记 `1.0`。

### 2.3 置信度

| 置信度 | 成立条件 |
|--------|---------|
| 高 | 覆盖率 = 100%，且每个计入事件的来源均为可核验原文（政府文件 / 公司公告 / 官方发布） |
| 中 | 存在媒体转述（`Wind 新闻检索` / `互联网查询`），或覆盖率 50%–99%，或**归属事件数为 0 的否定性结论** |
| 低 | 覆盖率 < 50%，或检索失败/关键字段缺失，或只有偏大偏小近似口径 |

### 2.4 判定

| 序号 | 条件 | 处置 | 原因码 |
|------|------|------|--------|
| C0 | `归属事件数 >= 3` 且 `合计金额 >= 10`（亿元） | **通过** | — |
| C1 | `（归属事件数 < 3 或 合计金额 < 10）` 且 `置信度 ∈ {高, 中}` | **淘汰** | `E2_CAPITAL_BELOW_THRESHOLD` |
| C2 | 同 C1 条件，但 `置信度 == 低` | **存疑** | `W_CAPITAL_UNRESOLVED` |

### 2.5 边界（脚本断言）

- 恰 `3` 起 / 恰 `10` 亿元 → **通过**（阈值取严格小于才淘汰）。
- 事件数为 0 且检索已执行、置信度「中」→ **淘汰**（不是存疑）。
- 覆盖率 50%–99% → 置信度「中」，仍可淘汰；覆盖率 < 50% → 置信度「低」，只能存疑。
- 同一事件重复出现在两条检索式里 → 去重后只计 1 起（脚本按去重键复核，`归属事件数` 与事件数组不一致时报 `E_SCHEMA`）。

## 3. Gate L：企业落地证据

### 3.1 数据点

| 字段 | 含义 | 必需 |
|------|------|------|
| `企业落地.龙头股[]` | 与本方向**最相关**的龙头，每方向 ≤3 家（先相关性，再按最新年度营业收入/市值排序） | 是 |
| `企业落地.订单` | `{口径, 本期值, 上年同期值, 同比, 期间, 主体, 来源, 置信度, dual_query}` | 是（可为 `null`） |
| `企业落地.预收款` | `{口径, 本期值, 上年同期值, 同比, 报告期, 主体, 来源, 置信度, dual_query}` | 是（可为 `null`） |
| `企业落地.扩产公告` | `{数量, 是否>=2可核验, 窗口, 关键词, 来源, 置信度}` | 是（可为 `null`） |
| `企业落地.置信度` | 三项置信度的 min | 是 |

- **订单口径**：`新签订单` / `在手订单` / `合同金额` 三选一并写清；同比 = 本期值 ÷ 上年同期值 − 1，期间长度必须一致，否则 `W_ORDER_CALIBER_INCOMPARABLE` 且该子项按**未命中**。
- **预收款口径**：`合同负债`（含预收款项，若列示）；同比 = 本期 ÷ 上年同期 − 1。
- **扩产公告**：近 12 个月，关键词 = 扩产/扩能/新增产线/产能建设/投资建设/募投项目/环评/扩建；判定的是**布尔「≥2 起可核验公告（标题 + 日期 + 来源可得）」**而非精确总数，故可判「高」；因 `get_company_announcements` 的 `top_k` 非穷尽，记 `W_ANNOUNCEMENT_TOPK_LIMITED`。
- **近似口径**：三项中任一只有偏大/偏小近似口径可用时，**该子项按未命中计**（向下修正），记 `W_PROXY_DOWNGRADED` 并写明修正逻辑。
- **龙头缺失**：不足 3 家记 `W_LT3_LEADERS`（不阻断）；一家都取不到 → 该维度关键项缺失 → 存疑。

### 3.2 阈值（严格大于）

| 子项 | 阈值 | 相等时 |
|------|------|-------|
| 订单同比增长率 | `> 20%` | `== 20%` → **未命中** |
| 预收款同比增长率 | `> 15%` | `== 15%` → **未命中** |
| 近 12 个月扩产公告数量 | `> 1`（即 ≥2） | `== 1` → **未命中** |

### 3.3 判定

| 序号 | 条件 | 处置 | 原因码 |
|------|------|------|--------|
| L0 | `置信度 == 高` 且 `命中项数 >= 2` | **通过** | — |
| L1 | `置信度 ∈ {高, 中}` 且不满足 L0 | **淘汰** | `E3_LANDING_INSUFFICIENT` |
| L2 | `置信度 == 低`，或三项中任一为 `null`（未取数） | **存疑** | `W_LANDING_UNRESOLVED` |

### 3.4 边界（脚本断言）

- 置信度「中」时**命中 3 项也淘汰**（硬性要求置信度为高）。
- 置信度「高」且命中恰 `2` 项 → **通过**。
- 置信度「高」且命中 `1` 项 → **淘汰**。
- 任一项未取数（`null`）→ 维度置信度必然 ≤ 低 → **存疑**（不淘汰）。
- 扩产公告 `数量 == 1` 且订单、预收款均命中 → 命中项数 2 → 若三项置信度均高则通过。

## 4. 结论聚合与排序

```
结论 = 淘汰  若任一关判为淘汰（原因码全部保留，用 `；` 连接）
结论 = 存疑  否则若任一关判为存疑（列出存疑维度）
结论 = 通过  否则
```

**排序键（脚本执行，LLM 不得手工排序）**：

1. 结论档位：`通过` → `存疑` → `淘汰`
2. 组内按 `产业资本.合计金额` 降序
3. 仍并列 → 按标准名字符串序（确定性 codepoint 比较）

## 5. 原因码与警告码汇总

### 5.1 淘汰原因码

| 码 | 关卡 | 含义 |
|----|------|------|
| `E1_POLICY_NOT_SUPPORTED` | P | 政策支持度不足（子码见 §1.2） |
| `E2_CAPITAL_BELOW_THRESHOLD` | C | 归属事件数 < 3 或 合计金额 < 10 亿元 |
| `E3_LANDING_INSUFFICIENT` | L | 企业落地证据不满足硬性指标 |

### 5.2 警告码（不阻断，进入 `warnings[]`）

| 码 | 含义 |
|----|------|
| `W_POLICY_UNRESOLVED` | 命中政策淘汰条件但置信度不足 → 存疑 |
| `W_CAPITAL_UNRESOLVED` | 命中资本淘汰条件但置信度为低 → 存疑 |
| `W_LANDING_UNRESOLVED` | 企业落地证据置信度为低或关键项缺失 → 存疑 |
| `W_PROXY_DOWNGRADED` | 近似口径已向下修正为未命中 |
| `W_ORDER_CALIBER_INCOMPARABLE` | 订单同比期间长度不一致，按未命中 |
| `W_ANNOUNCEMENT_TOPK_LIMITED` | 扩产公告计数受检索条数限制，非精确总数 |
| `W_EVENT_AMOUNT_MISSING` | 投资事件金额缺失，未计入事件数与金额 |
| `W_EVENT_DUPLICATE_DEDUPED` | 投资事件重复命中同一去重键，只计 1 起 |
| `W_FIELD_RECOMPUTED` | 可复算字段（事件数/金额/覆盖率/命中项/置信度）输入值与脚本重算值不一致，已以脚本值为准 |
| `W_CAPITAL_COVERAGE_LOW` | 投资事件金额覆盖率 < 100% |
| `W_CATALOG_VERSION_UNCONFIRMED` | 目录现行版本未能确认 |
| `W_CATALOG_STALE_LOCAL` | 本地目录文档版本落后于现行版本 |
| `W_CATALOG_MISSING` | 本地目录文档缺失，目录判定退回联网 |
| `W_CATALOG_CROSSCHECK_FAILED` | 目录文档与官方 OFD 附件交叉校验未通过 |
| `W_DUAL_QUERY_EMPTY` | 双查询已发出但返回空 |
| `W_LT3_LEADERS` | 龙头股少于 3 家 |
| `W_CONFIDENCE_UPGRADED` | 互联网/第三方来源被标「高」→ 自动降为「中」 |
| `W_FX_ASSUMED` | 汇率缺失或使用假定值 |

## 6. 判定自检

```
□ 三关是否都跑（未因先淘汰就跳过后续取数，导致主表数据列缺失）？
□ 淘汰是否都以"证据充分"为前提？数据缺失/低置信度是否一律进存疑而非淘汰？
□ 政策：限制类/淘汰类是否无条件淘汰？鼓励类+0 条是否淘汰？置信度非高是否不淘汰？
□ 资本：恰 3 起 / 恰 10 亿元是否通过？金额缺失事件是否未计入事件数与金额？
□ 资本：归属判定是否逐条有理由？被排除事件是否全部留痕？
□ 落地：三项阈值是否按"严格大于"比较（20%/15%/1 起）？
□ 落地：近似口径命中的子项是否已按未命中向下修正并写明逻辑？
□ 落地：置信度=中 且命中 3 项是否仍淘汰？任一项未取数是否进存疑？
□ 结论聚合、排序是否全部来自脚本（未手工排序）？
```
