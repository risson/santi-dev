## 2. 输出结构（markdown）

报告固定顺序：**标题 → 结论先行（含跳过方向）→ 排序口径 → 市值口径 → 产业链层级口径 → 事件—影响环节绑定表 → 7 列主表 → 附录 A–C → warnings → 免责声明**。

### 2.1 事件—影响环节绑定表（在主表之前）

表头固定 7 列且顺序固定：

```markdown
### 事件 — 影响环节绑定

| 细分产业方向 | 产业链层级 | 事件标题 | 事件日期 | 影响定级 | 传导强度 | 来源文件 |
|------|------|------|------|------|------|------|
| 固态电解质 | 上游原材料/耗材 | 新型电池产业十五五规划 | 2026-09-28 | A级 | 一级传导/高 | …json |
| 固态电解质 | 上游原材料/耗材 | 固态电池中试线量产进展 | 2026-10-08 | B级 | 一级传导/中 | …json |
| 储氢瓶 | 中游制造/集成 | [已跳过] | 未标注 | 未标注 | 未标注 | 跳过原因：未在任何事件文件中命中 |
```

- 同一方向的多个事件**逐行展开**（顺序 = 来源文件字典序）；`产业链层级` 是**方向级**属性，因此每行复写同一值（不依赖合并单元格，文本与表格解析都稳定）；
- `产业链层级` 取方向级声明值（santi-3「通过」/ 方向清单）> 绑定表条目 > 绑定事件 `事件[0]`；无来源写 `未标注`；
- 缺失的日期/定级/强度写 `未标注`（**不臆造**）；
- 被跳过方向在本表内以一行列出，`产业链层级` 仍显示（便于复核该方向本属哪一层），来源文件列写 `跳过原因：…`；
- 全部方向都绑定成功时本表只含绑定行，不得删除本表。

|------|------|------|------|------|------|------|
| 固态电解质 | 上游原材料/耗材 | 002709.SZ | 天赐材料 | 466.28 亿元 | 次要受益 | 相关业务占比 93.05%（近似口径[待验证]） + 占比>20%（口径偏大，按规则不计为核心受益） + 市值 466.28 亿元（方向内中位数 247.07 亿元，弹性中） |

**单元格格式**

| 列 | 格式 | 示例 |
|----|------|------|
| 细分产业方向 | 标准名（来自 A） | `固态电解质` |
| 产业链层级 | 四层标准枚举之一：`上游原材料/耗材` / `上游核心零部件/设备` / `中游制造/集成` / `下游应用`；无来源写 `未标注` | `上游原材料/耗材` |
| 股票代码 | Wind 代码（A 股） | `002709.SZ` |
| 股票名称 | Wind 证券简称 | `天赐材料` |
| 流通市值 | `{千分位} 亿元`；缺失写 `[数据暂不可用]` | `466.28 亿元` |
| 推荐层级 | `核心受益` / `次要受益` / `观察标的` | `次要受益` |
| 层级解读 | 按 `tiering-rules.md` §4 模板生成 | 见上 |

**排序**：产业方向（输入顺序）→ 推荐层级 → 流通市值升序 → 股票代码字典序（见 `tiering-rules.md` §3）。
报告开头固定写明「结论先行 / 排序口径 / 市值口径 / 产业链层级口径」四行；结论先行行需带 `；跳过 K 个未绑定事件的方向（…）`（K=0 时省略）；
产业链层级口径行形如 `**产业链层级口径**：来自 santi-3「通过」条目或事件文件原文（四层枚举，变体已归一）；有效方向 N 个，已标注 n 个[，未标注 m 个]。`（只统计有效方向）。

## 4. 对话回复规范

用户未指定输出方式时默认落盘；落盘后**只报**：

1. 结果文件路径（JSON + markdown + `inventory.json`；走 extract 时附方向清单与绑定表路径）
2. 一行摘要：`共 N 个方向（有效 n / 跳过 k），入表 M 只（核心受益 a / 次要受益 b / 观察标的 c）`
3. **被跳过的方向与原因**：逐条列出 `方向名 — 原因（未在任何事件文件中命中 / 事件载荷为空 / binding 中未出现）`；无跳过写「无」
4. **产业链层级分布**：逐条列出 `方向名 — 产业链层级（来源：santi-3「通过」/ 方向清单 / 事件文件）`；`未标注` 的明确写出
5. **降级与 `[待验证]` 清单**：逐条列出方向/标的与要素名
6. **warnings 摘要**：各警告码计数（`W_*` 码 + 条数）
7. 排序与口径一行：`排序 = 产业方向 → 推荐层级 → 流通市值升序；市值口径 = 流通市值（Wind，元 → 亿元）；产业链层级 = 四层枚举（变体已归一）`
8. 免责声明：`数据来源：Wind 金融终端、公开信息 | AI 生成，仅供参考，不构成投资建议`

不重复整段 JSON；用户明确要求时才打印全文或改用 `--stdout`（此时摘要与警告走 stderr，保证 stdout 是纯 JSON）。
**禁止**给出买卖建议、目标价、涨跌幅预测。

| 项 | 规则 |

| **绑定表** | `<输出目录>/event-stock-mapper_binding_<YYYY-MM-DD>.json`（`绑定[]`，**必须传给 `validate`/`rank` 的 `--binding`**） |
| 中间数据 | `<输出目录>/inventory.json`（Step 3 生成，供复核与重跑） |
| 编码 | UTF-8 无 BOM，LF 换行，末尾换行；纯 JSON 不包代码块、无前后缀文字 |
| 同名文件 | 默认覆盖，并在回复中说明覆盖的是哪个路径 |
| `--stdout` | 只打印 JSON 到标准输出，不落盘；摘要与警告改走 **stderr** |
| 禁止 | 不得写死绝对路径/用户名/平台专有路径；不得写技能自身目录；运行期不得写 `shared/` |
| 写入失败 | 如实说明原因（含沙箱/权限拒绝），改为对话输出，**不得谎报已写入** |
