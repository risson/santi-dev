## 2. 主表（markdown，按增长倍数由大到小）

表头**固定 10 列且顺序固定**，不得增删列或改名：

```markdown
| 细分产业方向 | 截至最新年度的市场规模 | 营收增速 | 渗透率及趋势 | 预测3-5年市场规模 | 置信度 | 龙头股 | 龙头股市值之和 | 增长倍数 | 备注 |
|------|------|---------|---------|---------|---------|---------|------|------|------|
```

**单元格格式**

| 列 | 格式 | 示例 |
|----|------|------|
| 细分产业方向 | 标准名（替换生效时为细分领域名） | `固态电解质材料` |
| 截至最新年度的市场规模 | `{千分位}亿元（{年份}）`，原币种非人民币时写 `{原值}{原单位}≈{换算值}亿元人民币（{年份}）` | `4,560亿元（2025）` |
| 营收增速 | `{1 位小数}%（{window} CAGR）`；不可得写 `未取数` | `15.8%（2022-2024 CAGR）` |
| 渗透率及趋势 | `{1 位小数}%（{趋势}）`；不可得写 `未取数` | `22.0%（向上）` |
| 预测3-5年市场规模 | 同市场规模列格式 + `（{as_of_year} 测算，{horizon}）` | `12,025.68亿元人民币（原值 1,689亿美元，2026 测算，3年）` |
| 置信度 | `高`/`中`/`低`；同名下多来源时取最保守值 | `中` |
| 龙头股 | 最多 3 家，`{代码} {简称}({市值亿元})`，`；` 分隔 | `300308.SZ 中际旭创(8,258亿元)` |
| 龙头股市值之和 | `{千分位}亿元`；非人民币先换算 | `8,258亿元` |
| 增长倍数 | 2 位小数；不可计算写 `不可计算（原因）` | `1.46` |
| 备注 | 分号分隔的短句：替换逻辑 / 口径降级 / `[待验证]` / 置信度下调 / 龙头不足 3 家 | `原「固态电池电解质」渗透率 62% 淘汰…；预测为第三方测算，口径偏大 [待验证]` |

**市值之和不足 3 家**时：`龙头股市值之和` 用可得家数求和，备注追加 `仅 N 家龙头可取数`。
**倍数不可计算**时：该行仍进主表（便于核对），排在最末，`增长倍数` 写 `不可计算（分子缺失）` / `不可计算（市值之和为 0）`。

## 3. 对话回复规范

用户未指定输出方式时默认落盘；落盘后**只报**：

1. 结果文件路径（JSON + markdown）
2. 一行摘要：`入表 N 个方向，Top {top_n}：{名称1}({倍数1}x) / {名称2}({倍数2}x) / …`
3. **淘汰与替换**：淘汰原因统计（各原因码计数）+ 替换记录（若有）
4. **`[待验证]` 清单**：所有第三方测算/互联网来源的要素，逐条列出方向与要素名
5. 一行口径提示（分子/分母实体范围不同）

不重复整段 JSON；用户明确要求时才打印全文或改用 `--stdout`。

## 4. 文件落位

| 项 | 规则 |
|----|------|
| 默认目录 | 用户指定 `--out`；未指定 → `<当前工作区根目录>/market-space-rank/` |
| 文件名 | `market-space-rank_ranked_<YYYY-MM-DD>.json` 与 `market-space-rank_ranked_<YYYY-MM-DD>.md` |
| 中间产物 | `<输出目录>/inventory.json`（Step 4 生成，供复核与重跑） |
| 编码 | UTF-8 无 BOM，末尾换行；纯 JSON 不包代码块、无前后缀文字 |
| 同名文件 | 默认覆盖，并在回复中说明覆盖的是哪个路径 |
| `--stdout` | 只打印 JSON 到标准输出，不落盘；此时摘要与警告改走 **stderr**，保证 stdout 是纯 JSON（可直接管道给下游程序） |
| 禁止 | 不得写死绝对路径/用户名/平台专有路径；不得写技能自身目录 |
| 写入失败 | 如实说明失败原因（含沙箱/权限拒绝），改为对话输出，**不得谎报已写入** |
