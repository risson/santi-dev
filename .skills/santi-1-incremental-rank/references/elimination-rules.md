# 首轮淘汰与细分替换规则（单一真源）

本文件定义 Step 2 的全部判定：渗透率淘汰、更细分领域替换、边界与原因码。脚本 `market-space-rank.mjs` 按本文件实现，`SKILL.md` 只引用不重复。

---

## 1. 淘汰规则（按顺序命中即停）

| 序号 | 条件 | 处置 | 原因码 | 备注写入 |
|------|------|------|--------|---------|
| E1 | `渗透率.current >= 0.50` | **淘汰**（先进入 §2 替换评估） | `E1_PENETRATION_GTE_50` | 按 §2.3 写替换逻辑或"未适用替换" |
| E2 | `渗透率.current` 为 `null`（未取数） | **保留**，排尾 | `W_PENETRATION_MISSING` | `渗透率未能取数，未适用淘汰规则` |
| E3 | `0.30 < 渗透率.current < 0.50` | **保留** | `W_PENETRATION_MIDBAND` | `渗透率 {X}% 处于 30%–50% 空白带，保留并按趋势观察` |
| E4 | `渗透率.current <= 0.30` | **保留**（无需替换） | — | 无 |

**边界口径（已与用户确认）**

- 淘汰阈值 `>= 50%`：**恰好 50% 淘汰**。
- 替换阈值 `<= 30%`：**恰好 30% 可用作替换**。
- 30%–50% 空白带**保留**，不淘汰、不需要替换，只在备注标注渗透率偏高与趋势。

## 2. 更细分领域替换

### 2.1 触发条件

仅当该方向被 **E1**（渗透率 ≥50%）淘汰时评估替换。E2–E4 不触发替换。

### 2.2 替换成立条件（必须**同时**满足）

| # | 条件 | 判定 |
|---|------|------|
| C1 | `市场规模.替换候选.name` 非空 | 该方向存在更具体的细分领域候选 |
| C2 | `替换候选.渗透率.current <= 0.30` | 更细分领域渗透率足够低 |
| C3 | `替换候选.渗透率.trend == "向上"` | 趋势向上（`稳定`/`向下`/`未标注` 均不成立） |
| C4 | 候选要素齐备 | 候选的 `市场规模`、`营收增速`、`渗透率`、`预测`、`龙头股` 五项均已填齐，且各数据点都有 `source` 与 `confidence` |

> **口径说明（重要）**：`替换候选` 是**同行业内可比口径的更细分领域**（例：父方向"固态电池制造装备"，候选"干法电极装备"），二者**并列而非嵌套**。因此候选渗透率**可以小于**父方向渗透率，不构成"子集渗透率高于全集"的矛盾。父方向自身口径的数据留在父条目字段中，不因替换被覆盖。

### 2.3 处置

**成立时**：

1. 主表该行的"细分产业方向"改为 `替换候选.name`，其全部要素（规模/增速/渗透率/预测/龙头股）取自 `替换候选`。
2. 父方向进入 `淘汰清单[]`，`剔除原因 = E1_PENETRATION_GTE_50`，并附 `替换为` 字段。
3. `替换记录[]` 记 `{ 原方向, 细分领域, 原方向渗透率, 细分领域渗透率, 细分领域趋势, 替换理由 }`。
4. 父方向若带 `原方向数据快照`，原样进入输出的 `替换记录[]`（仅留痕，不计入排序）。
5. 主表 `备注` 列按用户要求**简写替换逻辑**，格式固定：

   ```
   原「{原方向}」渗透率 {原渗透率}% 淘汰，以其细分领域「{细分领域}」替换（渗透率 {细分渗透率}%，趋势向上）
   ```

**不成立时**（C1–C4 任一不满足）：

1. 直接淘汰原方向，原因码 `E1_PENETRATION_GTE_50`。
2. 记 `W_DEEP_SEGMENT_REJECTED`，`备注` 写 `未适用替换：{具体未满足的条件}`，例如：
   - `未适用替换：无更细分领域数据`
   - `未适用替换：细分领域渗透率 41% 未降至 30% 以下`
   - `未适用替换：细分领域趋势为稳定，非向上`
   - `未适用替换：细分领域龙头股数据缺失`

### 2.4 替换的硬性边界

- **只做一级替换，不递归**：替换后的细分领域不再二次评估"它自己的更细分领域"。
- 替换只改变**参加排序的条目**，不改写用户原始列表：`原名[]` 必须保留原方向名。
- 替换后的名称**不进入**同义词词典/速查表（本技能不维护词典）。
- 替换不得跨方向合并（`深A → 原方向B` 这种映射禁止）。
- **禁止用"子集渗透率高于全集"的口径做替换**：候选与父方向必须是并列的可比口径；若某候选其实是父方向的组成部分且渗透率反而更高，说明口径自相矛盾，应作为数据错误修正取数，而不是拿来替换。

## 3. 增长倍数（不淘汰，仅排序；规则在此声明，计算在脚本）

```
增长倍数 = 归一后(预测.amount) / 归一后(Σ 龙头股.mcap)
```

- 归一：先按 `config.units` / `config.fx` 换算为**人民币亿元**，分子分母同单位后才可相除。
- 保留 **2 位小数**，四舍五入。
- **不可计算**（分子缺失、或市值之和为 0/缺失）→ 倍数置 `null`，给 `倍数不可计算原因`（`分子缺失` / `W_MCAP_ZERO`），**排序置于末尾**；末尾内部按标准名字典序。
- **口径提示（固定写入输出）**：分子是**行业整体**市场规模，分母是**龙头个股合计市值**，两者实体范围不同；该倍数用于同一张表内的横向比较，不代表个股潜在涨幅。禁止把该倍数表述为"上涨空间"。

## 4. 判定原因码汇总

| 码 | 类型 | 含义 |
|----|------|------|
| `E1_PENETRATION_GTE_50` | 淘汰 | 渗透率 ≥50% |
| `W_PENETRATION_MISSING` | 警告 | 渗透率未取数，未适用淘汰 |
| `W_PENETRATION_MIDBAND` | 警告 | 渗透率落在 30%–50% 空白带 |
| `W_DEEP_SEGMENT_REJECTED` | 警告 | 命中淘汰但更细分领域未达替换条件 |
| `W_MCAP_ZERO` | 警告 | 市值之和为 0 或缺失，倍数不可计算 |

## 5. 判定自检

```
□ 渗透率是否用小数比较（0.50 而非 50）？
□ 恰好 50% 是否淘汰、恰好 30% 是否允许替换？
□ 30%–50% 是否保留并写备注（未误淘汰）？
□ 渗透率缺失的方向是否保留并排尾（未误淘汰）？
□ 替换是否只做一级、未递归、未跨方向合并？
□ 替换成立时，主表显示的是细分领域名，备注是否按固定格式写了替换逻辑？
□ 替换不成立时，备注是否写明了具体未满足的条件？
□ 增长倍数不可计算的条目是否排尾并给出原因？
□ 输出是否写明"分子=行业整体、分母=龙头个股合计市值"的口径提示？
```
