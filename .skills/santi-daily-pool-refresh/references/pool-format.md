# 选股池契约（单一真源）

> 本文件是**选股池 CSV 格式、合并规则、归档规则**的唯一权威定义。
> 落实脚本：`scripts/santi-daily-pool.mjs` 的 `merge-pool` / `audit` / `scaffold`。

## 1. 文件位置与命名

| 项 | 值 |
|----|----|
| 目录 | `{根目录}/生产环境/当前选股池/` |
| 主文件 | `当前选股池.csv`（**唯一真源**，只维护最新条目） |
| 历史备份 | `{选股池目录}/历史/当前选股池_{yyyy-mm-dd-hh-MM}.csv`（每次写回主文件前自动复制一份） |
| 回溯快照库 | `{选股池目录}/历史回溯/当前选股池_asof-{yyyy-mm-dd}.csv`（**回溯轮**产物；不是主池、不参与主池备份） |
| 当选合并结果 | `{本轮运行目录}/step5-选股入池/选股池-合并后.csv`（与写回目标同内容，供复核） |
| 落选归档 | `{本轮运行目录}/选股池-归档.csv`（本轮被淘汰方向的全部行） |

> 主池（`当前选股池.csv` + `历史/`）与回溯快照库（`历史回溯/`）是**两套互不覆盖**的存储：
> 常规运行只动前者；回溯运行只动后者与运行目录。

## 2. 列定义（固定 7 列，顺序不可变）

| 列 | 含义 | 格式要求 |
|----|------|---------|
| `细分产业方向` | 方向标准名（同义词已归并） | 非空；与 santi-3 输出一致 |
| `产业链层级` | 四层枚举之一 | `上游原材料/耗材` / `上游核心零部件/设备` / `中游制造/集成` / `下游应用`；来源是绑定表或选股池原值，**不得 LLM 另判** |
| `股票代码` | Wind 代码 | 形如 `002709.SZ`；去重时按大写归一 |
| `股票名称` | 公司简称 | 非空 |
| `流通市值` | 市值（口径固定流通市值） | `466.28 亿元`（2 位小数 + 空格 + `亿元`）；取不到写空串，**不估值** |
| `推荐层级` | event-stock-mapper 档位 | `核心受益` / `次要受益` / `观察标的` |
| `层级解读` | 档位理由 | 可含 `[待验证]`；保留原样，不缩短、不改写 |

示例：

```csv
细分产业方向,产业链层级,股票代码,股票名称,流通市值,推荐层级,层级解读
固态电解质,上游原材料/耗材,002709.SZ,天赐材料,466.28 亿元,次要受益,相关业务占比 93.05%（近似口径[待验证]） + 占比>20%（口径偏大，按规则不计为核心受益） + 市值 466.28 亿元（方向内中位数 247.07 亿元，弹性中）
```

## 3. 字符与换行规范

| 项 | 规定 | 理由 |
|----|------|------|
| 编码 | **UTF-8 无 BOM**（默认） | 避免下游脚本把 BOM 当成列名的一部分 |
| BOM 可选 | `merge-pool --bom` | Windows Excel 直接双击打开需要 BOM；**仅在用户明确要求时使用** |
| 换行 | LF（`\n`） | 与仓库 `.gitattributes`（`* text=auto eol=lf`）一致 |
| 末尾 | 必须有一个换行 | 避免 diff 噪音与解析歧义 |
| 读入 | 自动剥离 BOM、兼容 CRLF | 用户手工用 Excel 编辑过也能读 |
| 引号 | 含 `,` `"` 换行的单元格用双引号包裹，`"` 转义为 `""` | 标准 CSV |

> 用户手工编辑产生的 BOM / CRLF **不会**导致运行失败；写回时统一规范为上面的形态。

## 4. 合并规则（`merge-pool`）

### 4.1 输入

| 参数 | 含义 |
|------|------|
| `--pool` | 读取/基准池（不存在 → 按空池处理；`-` → 显式空池基准） |
| `--pool-out` | **写回目标**（默认 = `--pool`）；与 `--pool` 不同时只写目标、不动读取基准 |
| `--new` | 本轮新增方向的入池明细（7 列同构；不存在 → 按"无新增标的"处理） |
| `--rank` | santi-3 输出（提供方向顺序；`结论 == "通过"` 才计入） |
| `--out` | 当选合并结果的另存路径 |
| `--archive` | 落选归档路径 |
| `--backup-dir` | 写前备份目录（默认 `<写回目标同级的>/历史/`） |
| `--no-backup` | 跳过写前备份（回溯轮写 as-of 快照时使用） |
| `--max-directions` | 方向数上限（默认 **5**） |
| `--report` | 合并报告 JSON 路径 |
| `--dry-run` | 只算不写（**不写主文件、不写 `--out`、不写 `--archive`、不备份**；只写 `--report`） |

### 4.2 算法

1. **合并行集合**：主文件全部行 + `--new` 全部行，按 `细分产业方向 + 股票代码（大写）` 去重（先出现者胜）。
2. **方向定序**：
   - 在 `--rank` 里有顺序的方向 → 按 santi-3 输出顺序；
   - 有行但没进 `--rank` 的旧方向 → 排在其后（字典序，不插队）；
   - `--rank` 里有名但池中无行的方向 → 进报告 `遗漏方向[]`（无行可归档）。
3. **截断**：保留前 `max-directions` 个方向（含各自全部行）；其余方向整体进归档。
4. **行序**：与方向序一致，逐方向输出其全部标的（保证人读的一览性）。
5. **写回**（非 `--dry-run`）：
   - 先把**写回目标**（存在且未 `--no-backup`）复制到 `{backup-dir}/<写回目标文件名>_{时间戳}.csv`；
   - 再原子写写回目标（临时文件 + rename）；
   - 同时写 `--out` 与 `--archive`。

### 4.3 旧方向保护

| 情形 | 处置 |
|------|------|
| 旧方向本次仍 `通过` santi-3 | **保留读取基准（`--pool`）里该方向原有全部行**（标的/市值/推荐层级/层级解读逐字不改）；不重新取标的、不覆盖 |
| 旧方向命中 C（重大利空） | 剔除出候选，不进 santi-3 入池结论 → 归档并记 `W_OLD_DIRECTION_DROPPED` |
| 旧方向进 santi-3 但结论为未通过 / 超出上限 | 归档并记 `W_DIRECTION_DROPPED_BY_CAP` 或 `W_OLD_DIRECTION_DROPPED` |
| 旧方向有行但本轮没进 santi-3 | 不插队、排在候选之后；超出上限则归档 |

> **口径漂移防线**：老方向改名（例如池中 `固态电解质`、本次标准名 `固态电解质材料`）不会自动合并。
> 必须先在 `manifest` 的 `A↔B 名称对账` 里确认并写入 `A-B名称映射.json`，否则同一个方向会以两个名字进池。
> 确认后 `来源标记` 按「A、B 都命中」处理（= `本次新增`），原名保留在该条 `原名[]` 里。

### 4.3.1 市值口径

写回与另存时，`流通市值` 一律由脚本规范为 `数字.两位小数 + 空格 + 亿元`（例如 `50.1` → `50.10 亿元`）。
上游给的是纯数字、已带 `亿元`、或带千分位都能正确归一；解析不出数字时**原样保留**，不猜测、不补值。

### 4.4 报告字段（`合并报告.json`）

```
generated_at / 技能 / 技能版本
选股池文件 / 选股池存在 / 排名文件 / 排名来源
读取基准 / 写回目标
方向数上限 / 合并前方向[] / 合并后方向[]
被剔除方向[{细分产业方向,原因,标的数,保留顺序}]
无排名方向[] / 遗漏方向[]
新增标的行数 / 去重行数 / 保留行数 / 归档行数
新增入池文件{exists,rows} / 备份 / 输出 / dry_run
```

## 5. 回溯（as-of）快照与写回目标

> 回溯运行 = 以历史日期 `D` 为锚定日重放一轮；**主池不可写**。触发与口径见 `pipeline-contract.md` §3。

### 5.1 快照库
- 路径：`{选股池目录}/历史回溯/当前选股池_asof-{yyyy-mm-dd}.csv`（一个日期一份，内容为该回溯轮的当选合并结果）。
- 用途：后续回溯（锚定日期更大的那天）把它当作 A 基准池（`asof-pool` 的第 3 优先级）。
- 命名正则固定 `^当前选股池_asof-\d{4}-\d{2}-\d{2}\.csv$`；不匹配的文件会被 `asof-pool` 忽略并记入 `回退链`。
- 与 `历史/` 的区别：`历史/` 是**主池写前备份**（时间戳到分钟），由主池变更产生；`历史回溯/` 是**回溯结果**（日期到天），由回溯轮产生。两者互不写入。

### 5.2 写回目标（`--pool-out`）
| 运行 | `--pool`（读取基准） | `--pool-out`（写回目标） | 备份 |
|------|---------------------|------------------------|------|
| 常规 | `{选股池文件}` | 省略（= `--pool`，写主池） | 写前把主池复制到 `历史/` |
| 回溯 | `{A基准池}`（空池用 `-`） | `{本轮运行目录}/step5-选股入池/选股池-{D}.csv` | `--no-backup`，不产生备份 |

- 写回目标与读取基准**分离**：`--pool` 只读，绝不被改写；备份对象永远是**写回目标**。
- 回溯轮收尾把该文件复制为 `历史回溯/当前选股池_asof-{D}.csv`（同一个 `D` 重跑则覆盖，`--no-backup` 保证不产生噪音备份）。
- **硬禁止**：回溯轮的 `--pool-out` 不得等于 `{选股池文件}`，也不得指向 `历史/` 下任何路径。

## 6. 上限口径

- **硬上限 5 个细分产业方向**（不是"本轮只新增 5 个"）：旧方向与新方向一起排队，超出者整体淘汰并归档。
- 标的数量**不设池级上限**：单方向标的数由 event-stock-mapper 的 T1–T6 与 Top 5–8 规则决定。
- 并行/并列：`--rank` 顺序即结论；santi-3 因并列扩展导致通过数 > 5 时，多出来的方向按顺序被截断并记入归档（报告里说明 `W_TIE_EXTENDED_TOP`）。

## 7. 审计（`audit`）

`audit --run-dir <本轮运行目录> --root <根目录> [--write]` 只读检查并产出 `运行清单.json`：

- 五步必需产物的存在性（缺失记 `W_AUDIT_MISSING_ARTIFACT`，退出码 1）；
- 各 JSON 可解析性；
- `step2` 事件文件的 `影响环节[]` 计数（形态校验）；
- 递归汇总所有产物里的 `warnings[]` 与 `降级说明[]`/`degradations[]`；
- 选股池行数、方向数与是否超限；
- `A_选股池已有` / `B_利好候选` / `C_重大利空` 三个集合（从 `santi-0-输入.json` 读）；
- **回溯轮**：读 `{本轮运行目录}/回溯锚定.json`，把摘要写进 `运行清单.回溯`（锚定日期 / 来源 / A基准池 / 主池未被改动 / 数据一致性）；
- `--write` 时合并已有 `运行清单.json`（保留 `调度` 段与 `回溯` 段不丢）。

## 8. 禁止项

- 不得写死绝对路径/用户名；不得写技能自身目录；不得写 `shared/`。
- 除 `merge-pool`（写回目标、与 `scaffold` 首次建空表头）外，**任何步骤都不得写选股池主文件**。
- **回溯轮不得写主池、也不得写主池的 `历史/`**；回溯产物只落 `{本轮运行目录}` 与 `历史回溯/`。
- 不得手工编辑 `当前选股池.csv` 的列顺序、列名或加列；需要新列必须先改本文件与脚本。
- 不得把归档结果直接删掉：归档是"为什么这个方向没了"的唯一证据。
- 不得手工重命名/搬移 `历史回溯/` 里的快照来"凑" A 基准池——基准必须由 `asof-pool` 判定。
