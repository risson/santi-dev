# 输出规范

> 本技能支持两个方向，由 `--direction bullish|bearish`（缺省 `bullish`）选择。两者 JSON 结构完全相同，
> 仅 `meta.技能` 之外的顶层 `方向口径` 与文件落位不同。下游消费前**必须**先看 `方向口径`。

## 1. 结果 JSON 结构


## 2. 字段说明

| 字段 | 必需 | 说明 |
|------|------|------|
| `meta` | 是 | 运行元信息；`词典命中别名数` / `词典新增别名数` 反映沉淀效果 |
| `方向口径` | 是 | **顶层**，`"利好"` 或 `"利空"`；本次 `--direction` 的口径标签。全量与 `--minimal` 模式都会输出 |
| `排序逻辑.比较链` | 是 | 固定为 `最高>非常高>高>中高>中>中低>低`（两个方向共用）；输出全 7 档，缺省 0，便于直接核对 |
| `细分产业方向[]` | 是 | **已按比较链降序排好**，不额外排序字段 |
| `细分产业方向[].细分产业方向` | 是 | 同义词归并后的**标准名** |
| `细分产业方向[].排序逻辑` | 是 | 该方向的七档计数（需求要求的"排序逻辑（各优先级的数量）"） |
| `细分产业方向[].别名` | 否 | 被并入该标准名的其他写法，去重、不含标准名本身 |
| `来源条目数` / `来源文件数` / `证据日期` | 否 | 追溯用；合并后为求和 / 去重集合 |
| `剔除清单[]` | 否 | 每条含 `细分产业方向`、`剔除原因`、`来源文件` |
| `warnings[]` | 否 | 结构化 `{码, 说明, 对象}`；码表见 SKILL.md |
| `剔除原因统计` | 否 | 各原因码计数，供 Step 2 一眼核对 |

**筛选口径**（详见 `ranking-rules.md`）：

- `方向口径 = 利好`：只保留「利好 + 推理置信度:高」；`中性`/`利空`/`中`/`低` 一律排除，不落「低」档。
- `方向口径 = 利空`：只保留「利空 + 推理置信度:高」；`中性`/`利好`/`中`/`低` 一律排除，不落「低」档。

## 3. 精简模式

`--minimal` 只输出 `方向口径` + `meta`（精简为 `generated_at` / `技能` / `技能版本`）+ `排序逻辑` + `细分产业方向[]`
（每项只含 `细分产业方向` + `排序逻辑`），用于下游程序直接消费。

## 4. 文件落位

| 项 | 规则 |
|----|------|
| 默认目录 | `<输入目录同级>/event-direction-rank-<slug>/`，`<slug>` 为 `bullish` 或 `bearish`；用户 `--out <目录>` 时以用户为准 |
| 文件名 | `event-direction-rank-<slug>_<主题简称>_<YYYY-MM-DD>.json` |
| `<主题简称>` | 解析输入文件名 `<上游技能名>_<主题>_<日期>.json` 的第 2 段；多文件时取第一个（按文件名字典序）；解析失败用 `event` |
| `<YYYY-MM-DD>` | 取输入 `事件.事件日期`（条目级覆盖优先），`未标注` 或缺失时取生成日期 |
| `inventory` 清单 | 默认 `<输入目录同级>/event-direction-rank-<slug>/inventory.json` |
| 同名文件 | 默认覆盖，并在回复中说明覆盖了哪个路径 |
| 编码 | UTF-8 无 BOM，末尾换行；纯 JSON，不包代码块 |
| 禁止 | 不得写死绝对路径/用户名/平台专有路径；不得写技能自身目录 |
| `--stdout` | 只打印 JSON 到标准输出，不落盘，**不回写词典** |

### 4.1 命名迁移说明

1.0.0 的产物名为 `event-direction-rank_<主题>_<日期>.json`（目录 `event-direction-rank/`）。
1.1.0 起改为方向显式命名：`event-direction-rank-bullish_*` / `event-direction-rank-bearish_*`，
并落到各自的方向目录。旧文件不会被改写或迁移；下游按 `方向口径`（顶层字段）而非文件名判方向，
旧文件缺该字段时按利好口径处理（向后兼容）。

## 5. 对话回复规范

落盘后**只报**：文件路径 + 本次方向口径 + 一行摘要（保留 N 条方向、Top 3）+ 本轮词典变更摘要
（命中别名数 / 新增别名数 / 冲突清单）。**不重复整段 JSON**；用户明确要求时才打印全文或 `--stdout`。

## 6. 下游混料警告

`方向口径 = 利空` 的结果**不可**与利好结果放进同一目录喂给 `santi-3-timeliness-rank` 的 `aggregate`
（它按内容形状识别输入，会求和七档计数）。默认目录已按方向隔离；santi-3 1.1.0 起也会跳过
`方向口径 = 利空` 的文件并记 `W_SKIPPED_BEARISH_DIRECTION`，但**不要依赖这道兜底**。
