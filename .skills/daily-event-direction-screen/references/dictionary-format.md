# 同义词速查词典（industry_segment_direction_dictionary.json）

## 1. 定位与路径

- **默认路径**：`[当前工作区根目录]/shared/industry_segment_direction_dictionary.json`
- **可覆盖**：`--dict <path>`，支持相对路径（按工作区根解析）与绝对路径。
- **首次运行自动创建**：目录不存在则创建，文件按 §2 结构初始化（`同义词: []`）。
- 词典是**跨事件长期资产**，默认纳入 git 跟踪，可 review、可回滚。
- 词典**禁止**写进技能自身目录。

## 2. 结构

```jsonc
{
  "_meta": {
    "格式版本": 1,
    "updated_at": "YYYY-MM-DDTHH:MM:SS+08:00",
    "条目数": 2,
    "别名数": 5
  },
  "同义词": [
    {
      "标准名": "固态电解质材料",
      "别名": ["固态电解质", "固态电池电解质", "硫化物固态电解质"],
      "来源": "llm-accumulate",
      "确认次数": 2,
      "备注": "上游材料环节常用简称"
    },
    {
      "标准名": "高端电池制造装备",
      "别名": ["高端锂电设备", "电池制造装备"],
      "来源": "manual",
      "确认次数": 3,
      "备注": "人工维护，不得被机器覆盖"
    }
  ],
  "冲突": [
    {
      "别名": "电池材料",
      "候选标准名": ["固态电解质材料", "硬碳负极与聚阴离子正极"],
      "最近确认": "固态电解质材料",
      "最近确认时间": "YYYY-MM-DDTHH:MM:SS+08:00"
    }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `来源` | `manual`（人工维护，**永不被机器覆盖**）\| `llm-accumulate`（技能运行自动沉淀） |
| `确认次数` | **每次运行、每个标准名最多 +1**（不是每命中一条 +1），用于识别长期未使用规则 |
| `别名` | 不含标准名本身；归一后去重；按加入顺序保留 |
| `_meta.条目数` / `别名数` | 由脚本计算写回，**不由 LLM 填** |
| `_meta.updated_at` | 仅在映射/别名/确认次数**实质变化**时更新；只读运行不产生 diff |
| `冲突` | 同一别名先后指向不同标准名时的留痕；保留原映射不覆盖，等人工裁决 |

### 手写一份词典

词典是纯 JSON，可直接手写。最简可用形态（人工锁定几条常用归并）：

```json
{
  "_meta": { "格式版本": 1 },
  "同义词": [
    { "标准名": "固态电解质材料", "别名": ["固态电解质"], "来源": "manual", "确认次数": 0 }
  ]
}
```

缺少的 `_meta` 子字段、`来源`（缺省 `manual`）、`确认次数`（缺省 0）、`冲突`（缺省 `[]`）会被脚本补全后写回。

## 3. 读写协议

```
Pass 0  加载词典 → 构建「别名 → 标准名」索引（按别名查，不按标准名查，保证同一条目可继续追加别名）
Pass 1  inventory：每个"细分产业方向"标记 命中词典 / 未命中
        ├─ 命中 → 直接解析为既有标准名，不消耗 LLM 判断
        └─ 未命中 → 进入 LLM 决议；脚本给出确定性"名称候选提示"（见 §5）
Pass 2  LLM 产出 canonical.json（只写增量）：
        {
          "canonical": { "原名": "标准名" },
          "不合并": [ { "名称": "...", "理由": "上下位关系，不可合并" } ],
          "notes": []
        }
Pass 3  rank：合并（词典命中 + canonical 增量）→ 校验 → 去重 → 聚合 → 排序 → 输出结果 JSON
Pass 4  回写词典（除 --no-dict-write）：新增别名/标准名入表，确认次数 +1，冲突入 冲突[]
```

**只读保证**：`inventory`、`--stdout`（干跑）、`--no-dict-write` **永不写词典**。

## 4. 回写规则

| 情况 | 行为 |
|------|------|
| 别名已存在且指向同一标准名 | `确认次数` +1；别名列表幂等合并 |
| 别名已存在但本轮映射到**不同**标准名 | **不覆盖**：保留原映射，写入 `冲突[]` + `W_CONFLICT`；本轮渲染按 `canonical.json` 优先并在回复中报告冲突 |
| 条目 `来源 = manual` | 一律不覆盖，`W_MANUAL_LOCKED`（只报不改） |
| 全新别名（同标准名） | 追加到该条目 `别名[]` |
| 全新别名 + 新标准名 | 新增 `同义词` 条目，`来源 = llm-accumulate`，`确认次数 = 1` |
| 新标准名与既有标准名归一后相同 | 挂到既有条目下，不新建 |
| 别名重名导致成环（A→B 而 B 又是别名） | 并查集收敛到最终标准名，`W_MERGE_CYCLE` 留痕 |
| 词典文件解析失败 / 结构不符 | `E_DICT_PARSE` / `E_DICT_SHAPE`：退出 1，**绝不覆盖原文件**，提示修复或换 `--dict` 路径 |
| 回写失败（沙箱 / 权限） | 如实报错，结果照常输出，**不得谎报已沉淀** |

**写入方式**：临时文件 + `rename` 原子写。

## 5. 名称候选提示（确定性，仅作提示）

脚本不判断语义，只产出候选信号供 LLM 参考：

1. **归一化同形**：去空格/全半角统一/去括号内容/去尾部"环节""方向"后完全相同的名字（最强信号）。
2. **名词片段**：按 `、` `与` `和` `及` `/` 切分后的片段集合有交集的名称组。
3. **共享子串**：共享长度 ≥2 的连续子串（如"固态电解质"与"固态电解质材料"）。

## 6. 裁剪

`dict:prune --unused <N>`：删除 `确认次数 < N` **且** `来源 = llm-accumulate` 的条目（或别名）。
`来源 = manual` 的条目与别名**永不删除**。裁剪前需 `--yes` 确认。
